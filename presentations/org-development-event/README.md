# جلسه توسعه سازمانی + منتورینگ گروهی — ارائه ترکیبی

فایل نهایی: **`توسعه-سازمانی-و-منتورینگ-گروهی.pptx`** — ۳۳ اسلاید، ۱۶:۹، فارسی راست‌به‌چپ.

این ارائه دو جلسه را در یک فایل جمع می‌کند: ابتدا **مقدمه توسعه فردی و
سازمانی** (چرایی تغییر، امواج تمدنی، مکاتب مدیریتی، جایگاه صنعت نفت و گاز و
مسیر گذار)، سپس **محتوای کامل منتورینگ گروهی** به‌عنوان اولین گام عملی.

تهیه و تنظیم: **وحید مجیدی** — www.coachroom.ir

---

## ساخت

```bash
cd presentations/org-development-event
python3 build.py
```

### شخصی‌سازی

```bash
python3 build.py \
  --presenter "وحید مجیدی" \
  --date "۱۴۰۴/۰۶/۱۵" \
  --org "شرکت ..." \
  --first-session "۱۴۰۴/۰۶/۲۹" \
  --time "۱۰:۰۰ تا ۱۱:۳۰" \
  --place "اتاق جلسات" \
  --contact "داخلی ۲۳۴"
```

| فلگ | کاربرد | پیش‌فرض |
|---|---|---|
| `--out` | مسیر خروجی | `توسعه-سازمانی-و-منتورینگ-گروهی.pptx` |
| `--font` | فونت فارسی | `IRANSans` |

| `--org` | نام واحد/سازمان | `[نام واحد / سازمان]` |
| `--first-session` | تاریخ اولین جلسه گروه | `[تاریخ]` |
| `--time` / `--place` / `--contact` | اطلاعات ثبت‌نام | `[…]` |

### بخش دوم — منتورینگ گروهی (اسلاید ۱۵ تا ۳۳)

همان محتوای `group-mentoring-event` با پنج فصل
(چرا / چیست / چطور / چه می‌شود / شروع)، شامل آناتومی جلسه ۹۰ دقیقه‌ای،
مهارت «به‌جای نصیحت بپرس»، قواعد فضای امن، چرخه شش‌ماهه و تمرین زنده.

روی هر ۳۳ اسلاید **یادداشت ارائه‌دهنده** به فارسی نوشته شده است.

| موج | دوره | مکاتب |
|---|---|---|
| **اول — کشاورزی** | تا ۱۷۵۰ | مدیریت سنتی (استادـشاگردی)، نظام صنفی |
| **دوم — صنعتی** | ۱۹۱۱ تا ۱۹۷۰ | مدیریت علمی (تیلور ۱۹۱۱)، مدیریت اداری (فایول ۱۹۱۶)، بوروکراسی (وبر ۱۹۲۲)، روابط انسانی (مِیو ۱۹۳۲)، نظریه X و Y (مک‌گرگور ۱۹۶۰)، نگرش سیستمی و اقتضایی (۱۹۷۰) |
| **سوم — دانش** | ۱۹۸۰ تا امروز | مدیریت کیفیت جامع (۱۹۸۰)، سازمان یادگیرنده (سنگه ۱۹۹۰)، مدیریت دانش (نوناکا ۱۹۹۵)، سازمان چابک (۲۰۰۱)، رهبری مربی‌گرا (۲۰۱۰+)، تیم‌های خودگردان |

در حالی که محیط کسب‌وکار وارد ستون موج سوم شده است.

## نکته فنی

بخش دوم مستقیماً از `../group-mentoring-event/build.py` بارگذاری می‌شود
(تابع `_load_mentoring`)، پس **محتوای منتورینگ در یک جا نگهداری می‌شود**.
هر اصلاحی در آن فایل، با یک بار اجرای دوباره، در این ارائه هم اعمال می‌شود.
شماره‌گذاری پاورقی با وصله‌کردن `T.footer` پیوسته نگه داشته شده
(اسلاید ۱۵ تا ۳۳ به‌جای ۲ تا ۲۰).
