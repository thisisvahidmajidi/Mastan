## 🧠 منطق ساختار

ارائه بر سه سؤالی که در پرسش شما آمده بنا شده، به‌علاوه یک بخش چهارم که
تصمیم گرفتم اضافه کنم:

```
   قلاب        چیستی         چرایی        نحوه اجرا      تجربه      تصمیم
  (۱–۳)        (۴–۶)         (۷–۱۰)        (۱۱–۱۴)       (۱۵)        (۱۶)
    │            │             │              │            │           │
 سؤالی که    این دقیقاً    چرا به درد     یک جلسه       همین حالا   چه کسی
 خودشان      چیست و      ما می‌خورد؟     واقعی چطور     یک دور      ادامه
 جواب        چه نیست                     پیش می‌رود     می‌زنیم     می‌دهد
 می‌دهند
```

### چهار تصمیم طراحی

**۱. یک بخش «تجربه زنده» اضافه کردم (اسلاید ۱۵).**
منتورینگ گروهی چیزی نیست که با توضیح دادن فروخته شود. ۳۰ دقیقه از جلسه یک دور
واقعی و کوچک است. کسی که یک بار تجربه‌اش کند، دیگر نیازی به متقاعد شدن ندارد.

**۲. به‌جای اسلایدهای جداکننده فصل، نشانگر فصل گذاشتم.**
سه چیپ کوچک بالای هر اسلاید (چیستی / چرایی / نحوه اجرا) که فصل جاری در آن پررنگ
است. مخاطب همیشه می‌داند کجای مسیر است، بدون هدر رفتن سه اسلاید.

**۳. اسلاید «هست / نیست» را قبل از استدلال آوردم (اسلاید ۵).**
بیشترین مقاومت در سازمان‌ها از سوءتفاهم می‌آید: «این هم یک کلاس دیگر است»،
«حرف‌هایم به مدیرم می‌رسد». تا این‌ها رفع نشود، هیچ استدلالی شنیده نمی‌شود.

**۴. جدول «نصیحت ← پرسش» را قلب ارائه کردم (اسلاید ۱۲).**
تنها مهارتی که مخاطب باید از این جلسه با خودش ببرد همین است. چهار جفت جمله
واقعی و قابل تقلید، به‌جای توضیح انتزاعی درباره «فرهنگ پرسشگری».

## 🚀 ساخت فایل

```bash
pip install python-pptx pillow
cd presentations/group-mentoring-kickoff
python3 build.py
```

### پر کردن جاهای خالی

```bash
python3 build.py \
  --presenter "وحید مجیدی" \
  --org "واحد توسعه منابع انسانی" \
  --date "۱۴۰۴/۰۶/۱۰" \
  --first-session "۱۴۰۴/۰۶/۲۴" \
  --time "۱۰:۰۰ تا ۱۱:۳۰" \
  --place "اتاق جلسات طبقه سوم" \
  --contact "داخلی ۲۴۱" \
  --font "IRANSans"
```

| سوییچ | کاربرد | پیش‌فرض |
|:---|:---|:---|
| `--presenter` | نام تسهیل‌گر (اسلاید ۱) | `[نام تسهیل‌گر]` |
| `--org` | نام واحد یا سازمان (اسلاید ۱) | `[نام واحد / سازمان]` |
| `--date` | تاریخ همین جلسه (اسلاید ۱) | `[تاریخ]` |
| `--first-session` | تاریخ اولین جلسه گروه (اسلاید ۱۶) | `[تاریخ]` |
| `--time` | ساعت جلسه (اسلاید ۱۶) | `[ساعت]` |
| `--place` | مکان جلسه (اسلاید ۱۶) | `[مکان]` |
| `--contact` | شماره تماس یا داخلی (اسلاید ۱۶) | `[داخلی]` |
| `--font` | نام فونت فارسی | `IRANSans` |
| `--out` | مسیر فایل خروجی | `با-هم-بلد-می‌شویم.pptx` |

## 🔤 نکته فونت

اگر `IRANSans` روی سیستم ارائه نصب نیست، یکی از این سه کار را بکنید:

1. فونت را نصب کنید (بهترین گزینه)
2. با فونت دیگری بسازید: `--font "B Nazanin"` یا `--font Vazirmatn`
3. در پاورپوینت: `File → Options → Save → Embed fonts in the file`

## 📂 نسبت با ارائه دیگر این مخزن

در `presentations/group-mentoring-01/` یک ارائه ۱۲ اسلایدی با عنوان
«از گفتگو تا سازمان یادگیرنده» وجود دارد که بر اساس یک قالب مشخص ساخته شده و
جهت‌گیری‌اش **راهبردی** است (سازمان یادگیرنده، پنج موج تحول، KSA).

این ارائه جهت‌گیری **عملیاتی** دارد: چیستی، چرایی، نحوه اجرا و یک تجربه زنده.
هر دو از کتابخانه مشترک `presentations/_lib/` استفاده می‌کنند.

| | `group-mentoring-01` | `group-mentoring-kickoff` |
|:---|:---|:---|
| تمرکز | چرا سازمان باید تغییر کند | چطور این جلسه کار می‌کند |
| مخاطب اصلی | مدیران و تصمیم‌گیران | شرکت‌کنندگان بالقوه |
| خروجی جلسه | تأیید طرح | ثبت‌نام داوطلب |
