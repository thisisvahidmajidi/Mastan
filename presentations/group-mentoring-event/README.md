# رویداد منتورینگ گروهی — ارائه جامع تصویرمحور

فایل نهایی: **`رویداد-منتورینگ-گروهی.pptx`** — ۲۰ اسلاید، ۱۶:۹، فارسی راست‌به‌چپ.

این ارائه، نسخه کاملِ رویداد است و محتوای هر دو ارائه پیشین
(`group-mentoring-01` و `group-mentoring-kickoff`) را در یک روایت واحد جمع کرده
و **هر ۱۴ تصویر تولیدشده برای این رویداد** را در دل محتوا به کار گرفته است.

---

## ساخت

```bash
cd presentations/group-mentoring-event
python3 build.py
```

### شخصی‌سازی

```bash
python3 build.py \
  --presenter "نام تسهیل‌گر" \
  --date "۱۴۰۴/۰۶/۱۵" \
  --org "واحد توسعه سرمایه انسانی" \
  --first-session "۱۴۰۴/۰۶/۲۹" \
  --time "۱۰:۰۰ تا ۱۱:۳۰" \
  --place "اتاق جلسات طبقه سوم" \
  --contact "داخلی ۲۳۴" \
  --font "IRANSans"
```

| فلگ | کاربرد | پیش‌فرض |
|---|---|---|
| `--out` | مسیر خروجی | `رویداد-منتورینگ-گروهی.pptx` |
| `--font` | فونت فارسی | `IRANSans` |
| `--date` | تاریخ روی جلد | `[تاریخ]` |
| `--presenter` | نام تسهیل‌گر | `[نام تسهیل‌گر]` |
| `--org` | نام واحد/سازمان | `[نام واحد / سازمان]` |
| `--first-session` | تاریخ اولین جلسه گروه | `[تاریخ]` |
| `--time` | ساعت جلسات | `[ساعت]` |
| `--place` | محل برگزاری | `[مکان]` |
| `--contact` | شماره/داخلی تماس | `[داخلی]` |

اگر فونت IRANSans روی سیستم مقصد نصب نیست، با `--font "B Nazanin"` یا
`--font "Vazirmatn"` بسازید.

## بازبینی بصری

بدون نصب PowerPoint، با رندرکننده داخلی:

```bash
python3 ../_lib/render.py رویداد-منتورینگ-گروهی.pptx -o /tmp/e
python3 ../_lib/render.py رویداد-منتورینگ-گروهی.pptx -o /tmp/e --only 4,19
```

خروجی، تصویر PNG هر اسلاید با کیفیت ۱۱۰ DPI است. رندرکننده فونت‌ها را از
`~/.fonts` می‌خواند (`--font-dir` برای مسیر دیگر).

## اصول طراحی

- پالت سه‌رنگه: سرمه‌ای `#1B4965`، نارنجی `#FF6B35`، سفید — به‌همراه رنگ‌های
  کمکی محدود برای تفکیک معنایی (سبز = «هست»، قرمز = «نیست»).
- بدون ایموجی؛ به‌جای آن شکل‌های هندسی، نشان‌های شماره‌دار و نوارهای رنگی.
- همه نمودارها (دونات ۷۰-۲۰-۱۰، نوار زمانی جلسه) **شکل‌های بومی و قابل ویرایش
  پاورپوینت** هستند، نه تصویر.
- کمینه اندازه قلم متن بدنه ۱۳ pt و متن‌های اصلی بالای ۱۶ pt.
- هر اسلاید یک پیام؛ فضای سفید سخاوتمندانه.
