## 🚀 ساخت دوباره فایل

```bash
pip install python-pptx pillow
cd presentations/group-mentoring-01
python3 build.py
```

### پر کردن جاهای خالی هنگام ساخت

به‌جای ویرایش دستی اسلایدها، مقادیر را از خط فرمان بدهید:

```bash
python3 build.py \
  --presenter "وحید مجیدی" \
  --org "واحد توسعه منابع انسانی" \
  --date "۱۴۰۴/۰۶/۱۰" \
  --first-session "۱۴۰۴/۰۶/۱۷" \
  --time "۱۰:۰۰ تا ۱۱:۳۰" \
  --place "اتاق جلسات طبقه سوم" \
  --font "IRANSans" \
  --out "ارائه-نهایی.pptx"
```

| سوییچ | کاربرد | پیش‌فرض |
|:---|:---|:---|
| `--presenter` | نام ارائه‌کننده (اسلاید ۱) | `[نام ارائه‌کننده]` |
| `--org` | نام واحد یا سازمان (اسلاید ۱) | `[نام واحد / سازمان]` |
| `--date` | تاریخ همین جلسه (اسلاید ۱) | `[تاریخ]` |
| `--first-session` | تاریخ اولین جلسه رسمی (اسلاید ۱۲) | `[تاریخ]` |
| `--time` | ساعت جلسه (اسلاید ۱۲) | `[ساعت]` |
| `--place` | مکان جلسه (اسلاید ۱۲) | `[مکان]` |
| `--font` | نام فونت فارسی | `IRANSans` |
| `--out` | مسیر فایل خروجی | `از-گفتگو-تا-سازمان-یادگیرنده.pptx` |

## 🔤 نکته مهم درباره فونت

فایل با نام فونت `IRANSans` ساخته می‌شود. اگر روی سیستمی که ارائه می‌دهید این فونت
نصب نباشد، پاورپوینت به‌صورت خودکار فونت جایگزین می‌گذارد و ممکن است چیدمان کمی
جابه‌جا شود. سه راه‌حل:

1. **نصب فونت** روی سیستم ارائه (بهترین گزینه).
2. **ساخت با فونت دیگر:** `python3 build.py --font "B Nazanin"` یا `--font Vazirmatn`.
3. **جاسازی فونت در فایل:** در پاورپوینت مسیر
   `File → Options → Save → Embed fonts in the file` را فعال و فایل را دوباره ذخیره کنید.

```bash

```
خروجی: ۱۲ فایل `shots/slide-01.png` تا `slide-12.png`.
برای رندر تنها چند اسلاید: `--only 3,7,12`

```bash
python3 preview.py "از-گفتگو-تا-سازمان-یادگیرنده.pptx" -o preview.html
```

## 🎨 اصول طراحی رعایت‌شده

- **یک پیام در هر اسلاید** — هیچ اسلایدی دو موضوع را هم‌زمان مطرح نمی‌کند.
- **حداقل اندازه فونت متن بدنه:** ۱۵pt برای زیرنویس‌ها و ۲۰pt به بالا برای متن اصلی؛
  تیترها ۳۳pt و تیتر جلد ۵۰pt.
- **حداکثر ۴ رنگ فعال** در هر اسلاید (آبی، نارنجی، سفید + یک رنگ وضعیت).
- **فضای خالی** حداقل ۳۰٪ در همه اسلایدها.
- **بدون انیمیشن** — هیچ افکت گذاری تعریف نشده است.
- **آیکون‌نگاری یکدست:** به‌جای اموجی (که در ویندوز رنگی و ناهماهنگ رندر می‌شود)
  از شکل‌های هندسی، بَج شماره‌دار و نوار رنگی استفاده شده تا در همه سیستم‌ها یکسان دیده شود.
