# گزارش تست نهایی پلتفرم CoachRoom OD — نسخه ۱.۶.۰

## ۱. هدف این نسخه

- شفاف‌سازی وضعیت موجود سازمان با **مدل شش‌جعبه‌ای وایزبورد** در کنار مدل تعالی **EFQM**.
- بازنگری روایی و پایایی کل ارزیابی و اطمینان از یکپارچگی «ارزیابی → تشخیص → راهبرد → خروجی».
- نمایش جداگانه دیدگاه هر مدل و راهبرد پیشنهادی هر مدل تا مدیریت بر اساس سطح بلوغ انتخاب کند.
- هماهنگی کامل فرم، پایگاه داده، AJAX، داشبورد، گزارش و بلاگ بدون خطای خاموش.

## ۲. اصلاحات فنی انجام‌شده

### تشخیص دوگانه و ارزیابی ۴۸ سؤالی

| موضوع | جزئیات |
|---|---|
| بانک سؤال بلوغ | ۳۰ سؤال (۳ سؤال در هر یک از ۱۰ بُعد) برای سنجش موج سازمانی. |
| بانک سؤال وایزبورد | ۱۸ سؤال جدید در ۶ جعبه (اهداف، ساختار، روابط، پاداش، رهبری، مکانیسم‌های کمکی) بر اساس Weisbord, 1976. |
| فرم | بخش تشخیصی شش‌جعبه‌ای با همان مقیاس ۱ تا ۴ به‌صورت جداگانه و الزامی اضافه شد. |
| ذخیره | `question_key` و `question_label` برای هر ۴۸ سؤال در جدول `responses` ذخیره می‌شود. |
| AJAX | محدوده مطمئن شامل ۱۰ بُعد + ۶ جعبه وایزبورد؛ میانگین هر بُعد/جعبه از سؤال‌های همان حوزه محاسبه می‌شود. |

### روایی و پایایی

| موضوع | جزئیات |
|---|---|
| روایی محتوا | منبع هر بُعد در `validity_sources()` مشخص شده است: مینتزبرگ، برنز/استالکر، راجرز/فارسون، سنژ، CCL/SBI، دوئر، ادموندسون، وایتمور و وایزبورد. |
| پایایی | `reliability_data()` ضریب آلفای کرونباخ را برای سه مقیاس «کل (۴۸)، بلوغ (۳۰)، وایزبورد (۱۸)» محاسبه می‌کند. |
| شرط اعتبار | آلفا فقط وقتی نمایش داده می‌شود که حداقل ۳ پاسخ‌دهنده کامل وجود داشته باشد؛ در غیر این صورت پیام «داده کافی نیست» ظاهر می‌شود. |
| واحد پاسخ | پاسخ‌دهنده = ترکیب دوره، کاربر، واحد و نقش؛ داده نمایشی طوری اصلاح شد که هر نقش در هر واحد، ۴۸ سؤال کامل دارد. |

### ماتریس چندمدلی و انتخاب راهبرد

| موضوع | جزئیات |
|---|---|
| موتور بلوغ | `strategy_data()` بر اساس آستانه‌های امنیت روانی، بازخورد و ساختار، راهبردها را انتخاب می‌کند. |
| EFQM | `efqm_data()` نمرات را به ۹ معیار و امتیاز ۰ تا ۱۰۰۰ تبدیل می‌کند. |
| وایزبورد | `weisbord_data()` امتیاز ۶ جعبه، وضعیت هر جعبه و جعبه‌های بحرانی را نمایش می‌دهد. |
| ماتریس | `model_matrix()` سه دیدگاه را کنار هم قرار می‌دهد و راهبرد هر مدل را جدا نشان می‌دهد. |
| مربی‌گری | راهبرد «ارتقای سرپرستان به مربیان عملکردی» فقط با تأیید آستانه‌های آمادگی فعال می‌شود. |

### نمایش و یکپارچگی

| موضوع | جزئیات |
|---|---|
| داشبورد | کارت EFQM + بخش شش‌جعبه وایزبورد + ماتریس چندمدلی + روایی/پایایی. |
| گزارش مدیران | بخش تشخیص وایزبورد، راهبرد منتخب، OKR، جدول EFQM و اقدامات اولویت‌دار. |
| بلاگ | توضیح علمی شش‌جعبه وایزبورد، روایی/پایایی و منابع معتبر. |
| صفحه سلامت | ستون‌های سؤال‌محور، وضعیت وایزبورد، راهبرد و آلفا. |
| به‌روزرسانی زنده | بعد از هر ثبت، همه بخش‌های جدید با AJAX نوسازی و `selfTest()` اجرا می‌شود. |

## ۴. سناریوی تست کاربری توصیه‌شده در سایت

1. تب **ارزیابی سازمانی** را باز کنید؛ ۱۰ بُعد بلوغ (۳۰ سؤال) و ۶ جعبه وایزبورد (۱۸ سؤال) را ببینید.
2. واحد و نقش را انتخاب کرده و همه ۴۸ سؤال را ثبت کنید.
3. همان واحد را با نقش دیگر ارزیابی کنید؛ داده نقش قبلی حفظ شود.
4. به تب **داشبورد شاخص‌ها** بروید: بخش EFQM، شش‌جعبه وایزبورد، ماتریس چندمدلی و روایی/پایایی را بررسی کنید.
5. به تب **نقشه راه** بروید: راهبرد تطبیقی و دلیل فعال/غیرفعال‌بودن مربی‌گری را ببینید.
6. به تب **گزارش مدیران** بروید: نتیجه‌گیری، دستورالعمل ۹۰ روزه، OKR و تشخیص وایزبورد را بررسی کنید.
7. خروجی CSV را دانلود و ستون‌های ابعاد، واحدها و نقش‌ها را مقایسه کنید.

## ۵. نتیجه

پلتفرم اکنون سازمان را از سه لنز «موج بلوغ، EFQM و وایزبورد» به‌صورت جداگانه تشخیص می‌دهد و راهبرد هر مدل را به‌تفکیک ارائه می‌کند. روایی محتوا با منبع علمی و پایایی با آلفای کرونباخ شفاف سنجیده می‌شود. چرخه «ارزیابی ۴۸ سؤالی → تشخیص چندمدلی → انتخاب راهبرد → OKR → نقشه راه → گزارش» به‌صورت یکپارچه بسته شده است. نسخه تست‌شده به‌عنوان فایل `coachroom-od-platform.zip` تحویل داده می‌شود.
