# گزارش تست نهایی پلتفرم CoachRoom OD — نسخه ۱.۳.۰

## ۱. هدف این نسخه

- یکپارچه‌سازی کامل «ثبت ارزیابی نقش‌های مختلف → پردازش → تحلیل → خروجی مدیران».
- اطمینان از به‌روزرسانی امتیازها برای همه نقش‌ها (کارمند، سرپرست، مدیر میانی، مربی سازمانی).
- افزودن راهنمای واژه‌های تخصصی به‌صورت پنجره توضیح (Tooltip).
- افزودن توضیح کاربردی مدل EFQM در تب بلاگ.
- تست هماهنگی همه تب‌ها و رفع خطاهای احتمالی.

## ۲. اصلاحات فنی انجام‌شده

| موضوع | اصلاح |
|---|---|
| میانگین نقش/واحد | قبلاً همه نقش‌ها و واحدها از یک `scores` کلی استفاده می‌کردند؛ اکنون هر گروه (نقش/واحد) میانگین اختصاصی خود را دارد. |
| جایگزینی پاسخ | در ثبت جدید فقط پاسخ «همان نقش + همان واحد + همان بُعد» جایگزین می‌شود؛ پاسخ نقش‌های دیگر حفظ و در تحلیل باقی می‌ماند. |
| عدم به‌روزرسانی پس از ثبت | درخواست AJAX به لایه `data.data` وردپرس به‌درستی unwrap می‌شود و بعد از ثبت همه بخش‌ها (داشبورد، نقش‌ها، واحدها، EFQM، گزارش) به‌روزرسانی می‌شوند. |
| خطای `undefined` | همه توابع با getterهای امن (`getSummary`, `getRoles`, `getDims` و…) محافظت شده‌اند. |
| خروجی مدیران | بخش «اثبات ثبت» (آخرین ثبت، تعداد نقش‌ها، تعداد سطرها) و جدول امتیاز ابعاد به تفکیک نقش به گزارش اضافه شد. |
| تعریف واژه‌ها | Tooltip برای ESG، EFQM، RADAR، SBI، GROW، OKR، KPI، AAR، PDCA، SDGs، HSE، جلسه ۱:۱ و مفاهیم کلیدی. |
| تب بلاگ | بخش «مدل تعالی EFQM به زبان ساده» با ۵ توانمندساز، ۴ نتیجه و منطق RADAR اضافه شد. |
| تست خودکار | تابع `selfTest()` در مرورگر ۱۹ شناسه کلیدی، ۱۰ بُعد، آرایه نقش‌ها/واحدها/توصیه‌ها، ۹ معیار EFQM و کامل‌بودن scores هر نقش را بررسی می‌کند. |

## ۳. چک‌لیست تست اجراشده

- [x] `node --check coachroom-od-platform/assets/js/coachroom-od-platform.js` — بدون خطای سینتکس.
- [x] بررسی تعادل `{ }` و `[ ]` در تمام فایل‌های PHP — بدون مشکل.
- [x] مقایسه شناسه‌های DOM استفاده‌شده در JS با شناسه‌های موجود در HTML — هیچ شناسه گم‌شده‌ای وجود ندارد.
- [x] بررسی وجود همه پنل‌های تب: dashboard، assessment، roadmap، departments، blog، reports.
- [x] بررسی وجود جداول: واحدها، نقش‌ها، ابعاد-نقش (دو نسخه: تب واحدها و گزارش مدیران).
- [x] بررسی وجود ۹ معیار EFQM در ساختار داده.
- [x] بررسی خروجی CSV شامل ابعاد، واحدها و نقش‌ها.
- [x] بررسی شرط حفظ داده نقش‌ها هنگام ثبت همان واحد + همان بُعد توسط نقش دیگر.
- [x] بررسی Tooltip روی واژه‌های ESG و EFQM و سایر واژه‌های تخصصی با شرط جلوگیری از جایگزینی مجدد.

## ۴. سناریوی تست کاربری توصیه‌شده در سایت

1. تب **ارزیابی سازمانی** را باز کنید.
2. واحد را انتخاب و نقش «کارمند» را بگذارید؛ همه ۱۰ شاخص را ثبت کنید.
3. دوباره همان واحد را با نقش «سرپرست» ارزیابی کنید.
4. به تب **واحدها و روند** بروید: نمودار و جدول نقش‌ها باید هر دو نقش را با امتیاز جدا نشان دهد.
5. به تب **گزارش مدیران** بروید: بخش «اثبات ثبت»، جدول ابعاد به تفکیک نقش، تحلیل EFQM و اقدامات اولویت‌دار باید به‌روز شده باشد.
6. روی واژه ESG یا EFQM در هر جای محتوا hover کنید تا پنجره توضیح نمایش داده شود.
7. خروجی CSV را دانلود کنید و ستون‌های مربوط به نقش‌ها را بررسی کنید.

## ۵. نتیجه

چرخه «ورودی ارزیابی از همه نقش‌ها → پردازش وزنی → تحلیل → خروجی مدیران» به‌صورت یکپارچه بسته شده است. نسخه تست‌شده به‌عنوان فایل `coachroom-od-platform.zip` تحویل داده می‌شود.
