سامانه توسعه سازمانی مبتنی بر داده برای ارزیابی موج‌های سازمانی، ساختار، بازخورد، پرسش‌گری و نقشه راه مربیگری سرپرستان.

== Description ==

این افزونه یک پلتفرم کامل «توسعه سازمانی» برای سایت coachroom.ir است و برای سازمان‌های حوزه انرژی، نفت و گاز طراحی شده است.

قابلیت‌های اصلی:

* تشخیص موج سازمانی (موج یکم تا چهارم) و نمایش شاخص‌های دیداری.
* ارزیابی مولفه‌های ساختاری: رسمیت، پیچیدگی و تمرکز تصمیم‌گیری.
* سنجش مهارت‌های مربی‌گری: گوش دادن فعال، پرسش‌گری، بازخورد و امنیت روانی.
* نقشه راه ۳۰ / ۶۰ / ۹۰ روزه برای ارتقای سرپرستان به مربیان عملکردی.
* نمودارهای رادار، میله‌ای و روند به‌صورت کاملاً داخلی (بدون کتابخانه خارجی).
* داشبورد مدیران، جدول مقایسه واحدها، خروجی CSV و چاپ گزارش.
* تب «بلاگ و مبانی علمی» شامل مرور پنج موج سازمانی، دورنمای موج پنجم (انسان‌محوری، تاب‌آوری، پایداری) و منابع معتبر.
* ثبت ارزیابی به‌صورت یک درخواست یکپارچه از طریق فرم پلتفرم و بروزرسانی زنده شاخص‌ها.
* صفحه سلامت داده در تنظیمات برای راستی‌آزمایی چرخه ارزیابی تا خروجی.

== Installation ==

1. پوشه `coachroom-od-platform` را در `wp-content/plugins` کپی کنید (یا به‌صورت فایل zip در بخش افزونه‌ها نصب کنید).
2. افزونه را فعال کنید.
3. شورت‌کد زیر را در صفحه یا نوشته‌ای قرار دهید:
   `[coachroom_od_platform]`

== Frequently Asked Questions ==

= آیا برای نمودارها به CDN یا کتابخانه خارجی نیاز است؟ =
خیر. نمودارها با Canvas داخلی رسم می‌شوند و برای سایت‌های داخل ایران یا محیط‌های بدون اینترنت قابل استفاده هستند.

= چگونه نام و صنعت سازمان را تغییر دهم؟ =
از منوی CoachRoom OD → تنظیمات.
